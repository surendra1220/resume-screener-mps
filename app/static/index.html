TRANSPARENT BY DESIGN

          
Evidence over keywords.

          

            A conservative, inspectable rubric that keeps the hiring team in
            control.
          

          

            

              
Four evidence statuses

              

                Matched · 100% credit
A work or project statement
                describes using the skill with an action and the required
                facets. An explicit knowledge claim can qualify only where the
                JD permits it.
              

              

                Partial Match · 50% credit
Related project evidence
                exists, but a required facet is absent.
              

              

                Claimed but Unevidenced · 0% credit
The skill
                appears in a list or general claim without a concrete work
                action.
              

              

                Missing · 0% credit
No positive evidence was found.
                This is not proof the candidate lacks the skill.
              

            

            

              
A score you can inspect

              

                Mandatory requirements contribute 80%; good-to-have requirements
                contribute 20%. Each category uses a weighted average. If one
                category is absent, the remaining category contributes 100%.
              

              

                Optional matches cannot clear a mandatory gap. A “suitable”
                assessment requires every mandatory requirement to be matched.
              

              

                Alternatives mean any one may qualify. Required facets
                must be evidenced together. Employment ranges are unioned so
                overlaps are not counted twice.
              

              
Privacy & boundaries

              

                No external AI service is called. Name, age, nationality,
                marital status, contact details, and other personal attributes
                are excluded from scoring. Reports contain job-related excerpts
                only and expire from app memory after one hour or server
                restart.
              

            

          

          

            This is a local evidence-rules engine, not a verification service or
            a general-purpose language model. Review custom JD drafts and
            extracted text; confirm experience, dates, and outcomes in
            interview. Scanned documents need OCR.
